Псевдокод

Псевдокодът е запис на алгоритъм с думи и ключови думи, който прилича на програма, но не следва строго правилата на конкретен език. Пише се за хора – за да обмислиш решението, преди да програмираш.

ПсевдокодЗначениеPython
ВЪВЕДИ xвход от потребителяx = input()
ИЗВЕДИ xпокажи на екранаprint(x)
x ← 5присвояване („сложи 5 в x“)x = 5
АКО … ТО … ИНАЧЕ … КРАЙ_АКОусловиеif … : … else: …
ЗА i ОТ 1 ДО n … КРАЙ_ЗАцикъл с броячfor i in range(1, n + 1):
ДОКАТО условие … КРАЙ_ДОКАТОцикъл с условиеwhile условие:

Пример: сбор на числата от 1 до n

НАЧАЛО
    ВЪВЕДИ n
    s ← 0
    ЗА i ОТ 1 ДО n
        s ← s + i
    КРАЙ_ЗА
    ИЗВЕДИ s
КРАЙ

n = int(input("Въведи n: "))
s = 0
for i in range(1, n + 1):
    s = s + i
print(s)
  1. input() връща текст; int() го превръща в цяло число.
  2. Започваме сбора от 0.
  3. range(1, n + 1) дава 1, 2, …, n (горната граница не се включва!). Отстъпът (4 интервала) показва кои редове са в цикъла.
  4. След цикъла – без отстъп – извеждаме резултата.

Python – първите команди

Python е един от най-популярните езици в света – използва се за уеб, наука, анализ на данни и изкуствен интелект. Пише се кратко и четимо.

ОперацияЗнакПример → резултат
събиране, изваждане+ -7 + 2 → 9
умножение*7 * 2 → 14
деление/7 / 2 → 3.5
целочислено деление//7 // 2 → 3
остатък%7 % 2 → 1
степен**2 ** 3 → 8
сравнение== != < > <= >=5 >= 3 → True
Отстъпът е задължителен. В Python редовете вътре в if, for и while се пишат с 4 интервала навътре, а след условието има двоеточие :.
print("Здравей, 10 клас!") a = 17 b = 5 print("Сбор:", a + b) print("Частно:", a / b) print("Цяла част:", a // b, "остатък:", a % b)
ocenka = 5.25 if ocenka >= 5.5: print("Отличен") elif ocenka >= 3: print("Издържал") else: print("Слаб")

Къде да пишеш Python

  • Тук, в урока – полетата с бутон „▶ Изпълни“ пускат истински Python в браузъра (първия път се зарежда до 20 секунди).
  • Thonny (thonny.org) – безплатна среда за начинаещи. Инсталираш, пишеш в горното поле, натискаш зеления бутон ▶ (F5). Долу в „Shell“ е резултатът.
  • IDLE – идва с Python от python.org.
  • Онлайн – online-python.com, replit.com, Google Colab (за анализ на данни).
