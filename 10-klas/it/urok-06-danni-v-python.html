Списъци – много данни в една променлива

ocenki = [5, 6, 4, 5.5, 3, 6]
print(ocenki[0])      # първият елемент
print(ocenki[-1])     # последният
print(len(ocenki))    # брой елементи
ocenki.append(5)      # добави в края
print(sum(ocenki) / len(ocenki))
  1. Списъкът е в квадратни скоби, елементите – със запетая.
  2. Номерацията (индексът) започва от 0. Индекс -1 е последният елемент.
  3. len() – колко са елементите.
  4. append() добавя нов елемент.
  5. Средно аритметично = сбор / брой.
ФункцияДава
sum(l)сбор
max(l), min(l)най-голям, най-малък
sorted(l)подреден нов списък
l.count(x)колко пъти се среща x
round(x, 2)закръгляне до 2 знака
ocenki = [5, 6, 4, 5.5, 3, 6] print("Брой:", len(ocenki)) print("Най-висока:", max(ocenki)) print("Най-ниска:", min(ocenki)) sredno = sum(ocenki) / len(ocenki) print("Средно:", round(sredno, 2)) print("Подредени:", sorted(ocenki)) print("Шестици:", ocenki.count(6))
f-низове – удобен начин да вмъкнеш стойности в текст: print(f"Средно: {sredno:.2f}"). Каквото е във {}, се изчислява; :.2f значи „2 знака след точката“.

Цикъл по списък

С for елемент in списък: обхождаш всички елементи. Така броиш, сумираш и търсиш.

temperaturi = [3, -1, 5, 8, 12, 7, -2] studeni = 0 for t in temperaturi: if t < 0: studeni = studeni + 1 print("Дни под нулата:", studeni) print(f"Средна температура: {sum(temperaturi) / len(temperaturi):.1f} °C")
stapki = {"пон": 6200, "вт": 8100, "ср": 4300, "чет": 10250, "пет": 7600} for den, broi in stapki.items(): print(den, broi, "✅" if broi >= 8000 else "") nai = max(stapki, key=stapki.get) print("Най-активен ден:", nai, stapki[nai])
