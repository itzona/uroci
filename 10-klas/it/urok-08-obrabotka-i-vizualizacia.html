Обработка: филтриране, сортиране, групиране

df["uspeh"].mean()                      # средно на колона
df[df["telefon_chasa"] > 5]             # филтър: само редовете с > 5 ч
df.sort_values("uspeh", ascending=False) # сортиране, най-високите отгоре
df.groupby("klas")["uspeh"].mean()       # средно по групи
df["lyubim_predmet"].value_counts()      # колко пъти се среща всяка стойност
df = df.dropna()                         # махни редовете с липсващи стойности
df["ekran_min"] = df["telefon_chasa"] * 60  # нова колона
  1. Колоната се избира с името ѝ в квадратни скоби.
  2. Условието дава „да/не“ за всеки ред – остават само „да“.
  3. ascending=False – низходящо.
  4. Разделя на групи по клас и смята средното за всяка.
  5. Брои – чудесно за кръгова или колонна диаграма.
  6. Почистване и изчисляване на нова колона.

Визуализация с matplotlib

Всеки пример рисува диаграма. Смени цветовете, заглавията или колоните и пусни пак.

import pandas as pd import matplotlib.pyplot as plt df = pd.read_csv('anketa.csv') sredno = df.groupby("klas")["uspeh"].mean() plt.bar(sredno.index, sredno.values, color="#0b5cad") plt.title("Среден успех по класове") plt.ylabel("Успех") plt.ylim(0, 6) plt.show()
import pandas as pd import matplotlib.pyplot as plt t = pd.read_csv('temperaturi.csv') plt.plot(t["mesec"], t["temp"], marker="o", color="#d97706") plt.title("Средна месечна температура (приблизително), София") plt.ylabel("°C") plt.grid(True) plt.show()
import pandas as pd import matplotlib.pyplot as plt df = pd.read_csv('anketa.csv') broi = df["lyubim_predmet"].value_counts() plt.pie(broi.values, labels=broi.index, autopct="%1.0f%%") plt.title("Любим предмет") plt.show()
import pandas as pd import matplotlib.pyplot as plt df = pd.read_csv('anketa.csv').dropna() plt.scatter(df["telefon_chasa"], df["san_chasa"], color="#6d2f8e") plt.title("Телефон и сън") plt.xlabel("Часове с телефон на ден") plt.ylabel("Часове сън") plt.show() print("Корелация:", round(df["telefon_chasa"].corr(df["san_chasa"]), 2))
Корелация – число от −1 до 1, което показва колко са свързани две величини. Близо до −1: когато едната расте, другата намалява. Близо до 0: няма връзка. Внимание: корелацията не доказва причина! Може да има трета причина.
