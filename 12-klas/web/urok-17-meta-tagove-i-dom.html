Урок 17: HTML: мета тагове и HTML дървото (DOM)

Мета таговете се поставят в <head>, съдържат информация за страницата и не се визуализират директно.

Мета тагЗа какво служи
<meta charset="UTF-8">кодиране – как се изобразяват символите (кирилицата)
<meta name="description" content="…">кратко описание; ползва се от търсачките
<meta name="author" content="…">автор на страницата
<meta name="viewport" content="width=device-width, initial-scale=1.0">правилно показване на телефон

HTML дърво (DOM)

Елементите са подредени като дърво. DOM (Document Object Model) позволява на JavaScript да променя елементи и стилове в реално време.

HTML дървото: всеки елемент е възел, а вложените елементи са негови деца
html            ← корен (root)
 ├─ head        ← дете на html
 │   └─ title
 └─ body
     └─ header  ← дете на body (родител на h1)
         └─ h1  ← дете на header, наследник на body
ПонятиеЗначение
Корен (Root)винаги <html>, съдържа head и body
Възел (Node)всеки елемент в HTML
Родител / детеелемент, който съдържа друг / елемент, който е вътре директно
Наследницивсички елементи по-надолу в дървото

Опитай: натисни бутона – JavaScript намира родителя и децата на втория елемент от списъка.

💻 Задача за Notepad++

Подготви правилен head и изследвай HTML дървото.

  1. Направи head с meta charset, description, author, viewport и title.
  2. В body сложи div с два абзаца и списък от 3 елемента.
  3. На лист или в Notepad++ нарисувай дървото от html надолу – кой е родител и кой е дете.
  4. Добави бутон, който с JavaScript показва тага на родителя на първия абзац и броя деца на div-а (parentElement.tagName, children.length).

Как да работя в Notepad++?
  1. Отвори Notepad++ → File → New (Ctrl+N).
  2. Напиши кода на задачата.
  3. File → Save as… (Ctrl+Alt+S) → в „Save as type“ избери Hypertext Markup Language file → напиши името от задачата (с .html) → Save. Запазвай всичко в една папка за уроците.
  4. Отвори файла с двоен клик – ще се отвори в браузъра.
  5. След всяка промяна: Ctrl+S в Notepad++ и F5 в браузъра. Ако кирилицата е счупена – Encoding → UTF-8.
