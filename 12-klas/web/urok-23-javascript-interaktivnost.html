Урок 23: JavaScript – интерактивност

JavaScript добавя поведение: реакция на клик, промяна на текст, проверки и др. HTML = структура, CSS = външен вид, JS = поведение.

Код се пише в <script>. Функцията function име() { … } изпълнява код при извикване. alert("…") показва съобщение, а document.getElementById("id") намира елемент от страницата.

JavaScript „слуша“ за действия на потребителя и отговаря с код

Как се включва JavaScript – 3 начина

1) Вграден – директно в атрибут на събитие:

<button onclick="alert('Здравей!')">Кликни</button>

2) Вътрешен – в таг <script> (обикновено в края на body):

<script>
  alert("Здравей!");
</script>

3) Външен – отделен файл script.js, който се свързва (във файла няма таг script):

<script src="script.js"></script>
Променливата е кутия с етикет: името е на етикета, стойността е вътре

Как да работя в Notepad++?
  1. Отвори Notepad++ → File → New (Ctrl+N).
  2. Напиши кода на задачата.
  3. File → Save as… (Ctrl+Alt+S) → в „Save as type“ избери Hypertext Markup Language file → напиши името от задачата (с .html) → Save. Запазвай всичко в една папка за уроците.
  4. Отвори файла с двоен клик – ще се отвори в браузъра.
  5. След всяка промяна: Ctrl+S в Notepad++ и F5 в браузъра. Ако кирилицата е счупена – Encoding → UTF-8.
