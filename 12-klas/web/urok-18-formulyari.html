Урок 18: Формуляри

<form> събира данни от потребителя – регистрация, анкета, поръчка. Всяко поле е <input>, а видът му се определя от атрибута type.

Така изглежда формата и кой таг отговаря за всяка част от нея
ЕлементКакво прави
<input type="text">текстово поле
type="email", "password", "number"имейл, парола (скрити знаци), число
type="checkbox" / "radio"отметка (може няколко) / избор на един вариант
<select><option>падащ списък
<textarea>многоредов текст
<button type="submit">бутон за изпращане
label – надпис към полето; свързва се с него чрез for="ime" и id="ime".
placeholder – подсказка в полето, required – задължително поле. Радио бутоните от една група имат еднакво name.

Опитай: добави поле за телефон (type="tel") и направи имейла задължителен.

💻 Задача за Notepad++

Направи формуляр-анкета за училищна екскурзия.

  1. label и input type="text" за име – задължително (required).
  2. Поле type="number" за възраст и type="email" за имейл.
  3. Радио бутони за транспорт (автобус или влак – с еднакво name) и поне 3 отметки за дейности.
  4. select с 3 града и textarea за коментар с placeholder.
  5. Бутон за изпращане.

⭐ Бонус: Покажи с JavaScript съобщение „Благодарим, …!“ с въведеното име при изпращане.

Как да работя в Notepad++?
  1. Отвори Notepad++ → File → New (Ctrl+N).
  2. Напиши кода на задачата.
  3. File → Save as… (Ctrl+Alt+S) → в „Save as type“ избери Hypertext Markup Language file → напиши името от задачата (с .html) → Save. Запазвай всичко в една папка за уроците.
  4. Отвори файла с двоен клик – ще се отвори в браузъра.
  5. След всяка промяна: Ctrl+S в Notepad++ и F5 в браузъра. Ако кирилицата е счупена – Encoding → UTF-8.
