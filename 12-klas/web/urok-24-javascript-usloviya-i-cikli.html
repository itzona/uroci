Урок 24: JavaScript: условия, цикли и масиви

Програмите вземат решения с условия, повтарят действия с цикли и пазят няколко стойности в масив.

ПонятиеЗаписКакво прави
Условиеif (o >= 3) { … } else { … }избира кой код да се изпълни
Сравнение== != < > <= >=връща вярно или невярно
Логически&& (и), || (или)свързва няколко условия
Масивlet a = ["Иван", "Мария"];списък от стойности; a[0] е първият, a.length е броят
Цикъл forfor (let i=0; i<a.length; i++) { … }минава през всички елементи
Вляво: условие – програмата избира път. Вдясно: масив – елементите се номерират от 0
Масивите се броят от 0: първият елемент е a[0], вторият – a[1].

Опитай: добави още име в масива и още едно условие за оценка 4.

💻 Задача за Notepad++

Работи с масив, цикъл и условие – този път не с оценки.

  1. Направи масив с 5 любими филма или песни.
  2. С for цикъл ги изведи като списък на страницата (с innerHTML +=).
  3. Поле type="number" и бутон, които проверяват дали числото е четно или нечетно (операторът %) и показват отговора.
  4. Добави условие: ако числото е по-голямо от 100, покажи и „голямо число“.

⭐ Бонус: С for изведи таблицата за умножение на въведеното число до 10.

Как да работя в Notepad++?
  1. Отвори Notepad++ → File → New (Ctrl+N).
  2. Напиши кода на задачата.
  3. File → Save as… (Ctrl+Alt+S) → в „Save as type“ избери Hypertext Markup Language file → напиши името от задачата (с .html) → Save. Запазвай всичко в една папка за уроците.
  4. Отвори файла с двоен клик – ще се отвори в браузъра.
  5. След всяка промяна: Ctrl+S в Notepad++ и F5 в браузъра. Ако кирилицата е счупена – Encoding → UTF-8.
