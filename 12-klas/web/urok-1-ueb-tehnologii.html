Урок 1: Уеб технологии, стандарти и как работи интернет

Уеб технологиите са езици и инструменти за създаване на сайтове. Основните са три: HTML – какво има на страницата, CSS – как изглежда, JavaScript – как се държи.

ТехнологияРоляПример
HTMLмаркиращ език за структурата и съдържанието (не е програмен език!)<h1>Добре дошли!</h1>
CSSотделя външния вид от съдържанието; прилага стилове чрез селекториh1 { color: blue; }
JavaScriptпрограмен език за интерактивност – реагира на клик, въвеждане, променя съдържаниетоbutton.onclick = function() {…}

Организация и достъп до уеб съдържание

Хипертекстът е текст с връзки към други ресурси, а хипервръзката е елементът, върху който се кликва. Страниците се съхраняват на уеб сървър (компютър или софтуер, напр. Apache, Nginx), който приема заявките на браузъра и изпраща страниците. Обменът върви по протокол HTTP/HTTPS.

Как работи интернет (клиент – сървър):
1) въвеждаш адрес (URL) в браузъра; 2) браузърът праща HTTP заявка към сървъра; 3) сървърът връща HTML, CSS и други файлове; 4) браузърът показва сайта.
Така работи интернет: заявка → отговор → показване

Уеб стандарти

Стандартите са правила и препоръки, които осигуряват еднакво показване в различните браузъри и подобряват достъпността и сигурността. Разработва ги W3C (World Wide Web Consortium). HTML5 е създаден през 2008 г. и потвърден от W3C през 2014 г. CSS3 се развива на модули, а след 2020 г. W3C спира да номерира версиите на CSS.

Софтуер за създаване на сайтове

Текстови редактори (пишеш код): Visual Studio Code, Notepad++. Визуални редактори (без код, с графичен интерфейс): WordPress, Wix.

Анализ на страница с Developer Tools

Натисни F12 (или десен бутон → Inspect) върху всеки сайт, например bg.wikipedia.org. В таба Elements се вижда HTML структурата, в Styles – CSS стиловете, а в Network – заявките към сървъра.

Опитай: в примера по-долу HTML създава елемента, CSS задава вида и ефекта при посочване, а JavaScript – реакцията при клик.

💻 Задача за Notepad++

Опиши със свои думи как работят трите технологии и пътя на една заявка.

  1. Избери сайт, който познаваш (напр. на твоето училище).
  2. Напиши по едно изречение с конкретен пример: какво на този сайт е работа на HTML, какво – на CSS и какво – на JavaScript.
  3. Опиши по точки какво се случва от въвеждането на адреса му в браузъра до показването на страницата (URL → заявка → сървър → отговор).
  4. Посочи кой е клиентът и кой е сървърът в твоя пример и кой протокол се ползва.

⭐ Бонус: Обясни с една фраза разликата между HTTP и HTTPS.

Как да работя в Notepad++?
  1. Отвори Notepad++ → File → New (Ctrl+N).
  2. Напиши текста на задачата.
  3. File → Save as… → в „Save as type“ избери Normal text file → напиши името от задачата (с .txt) → Save.
  4. Ако кирилицата се чете неправилно – Encoding → UTF-8.
