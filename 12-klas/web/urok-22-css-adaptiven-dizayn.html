Урок 22: CSS: адаптивен дизайн, преходи и анимации

Сайтът трябва да изглежда добре на компютър, таблет и телефон – това е адаптивен (responsive) дизайн.

ПравилоКак се прави
ViewportВ head: <meta name="viewport" content="width=device-width, initial-scale=1"> – без него телефонът смалява цялата страница.
Гъвкави меркиПроценти, rem, max-width:100% за картинките, вместо фиксирани px.
Media query@media (max-width:600px) { … } – правилата важат само при екран до 600px.
Един и същ сайт променя подредбата си според ширината на екрана

Плавни промени и анимации

СвойствоЕфект
transition: .3s;промяната (напр. при :hover) става плавно
transform: scale(1.06);уголемява, завърта (rotate) или мести (translate)
@keyframes + animationсамостоятелна анимация на етапи
Подход „първо телефон“: пишеш стиловете за малък екран, а с media query добавяш подредбата за по-големите.

Опитай: прегледът е тесен, затова фонът се оцветява. Смени 350px на 100px и виж разликата.

💻 Задача за Notepad++

Направи адаптивна галерия от 6 кутии.

  1. В head добави meta viewport.
  2. Контейнер с display:flex; flex-wrap:wrap и 6 кутии в различни цветове.
  3. При :hover кутията да се завърта малко (transform:rotate(5deg)) с transition от .3s.
  4. С @media (max-width:600px) направи кутиите на цяла ширина, една под друга.
  5. Със @keyframes анимирай заглавието да се движи наляво-надясно.

⭐ Бонус: Смалявай прозореца на браузъра и запиши от каква ширина се сменя подредбата.

Адаптивна галерия

📁 Запази като: adaptivna.html

Как да работя в Notepad++?
  1. Отвори Notepad++ → File → New (Ctrl+N).
  2. Напиши кода на задачата.
  3. File → Save as… (Ctrl+Alt+S) → в „Save as type“ избери Hypertext Markup Language file → напиши името от задачата (с .html) → Save. Запазвай всичко в една папка за уроците.
  4. Отвори файла с двоен клик – ще се отвори в браузъра.
  5. След всяка промяна: Ctrl+S в Notepad++ и F5 в браузъра. Ако кирилицата е счупена – Encoding → UTF-8.
