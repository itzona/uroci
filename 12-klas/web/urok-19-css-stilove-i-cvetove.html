Урок 19: CSS – стилове и цветове

CSS (Cascading Style Sheets) определя как изглежда страницата. Записва се така:
селектор { свойство: стойност; }

Три начина за включване:
1) вътре в тага – style="…",
2) в <style> в head,
3) външен файл <link rel="stylesheet" href="style.css"> (най-добрият – една промяна важи за целия сайт).

Един и същ HTML – без и със CSS. CSS променя цветове, шрифтове, подредба и форма

Цветове – 4 начина

1. Име: red
2. HEX (шестнайсетичен код): #FF0000
3. RGB (червено, зелено, синьо): rgb(255, 0, 0)
4. HSL (тон, наситеност, осветеност): hsl(0, 100%, 50%)

color – цвят на текста, background-color – фон, font-size, text-align, background-image – фоново изображение.

Как се включва CSS – 3 начина

1) Вграден (inline) – директно в тага, важи само за него:

<p style="color:red; font-size:20px;">Червен текст</p>

2) Вътрешен (internal) – в <style> в <head>, важи за цялата страница:

<head>
  <style>
    p { color: red; }
  </style>
</head>

3) Външен (external) – отделен файл style.css, свързан с <link>. Важи за всички страници, които го свързват:

<!-- в index.html -->
<link rel="stylesheet" href="style.css">

/* във файла style.css (без таг style!) */
p { color: red; }
Ако стиловете си противоречат, печели най-конкретният: вграден → вътрешен/външен. За истински сайтове се ползва външен файл.

Как се пише CSS правило

селектор  {  свойство: стойност;  свойство: стойност;  }
   h1     {  color: blue;          font-size: 30px;     }

Селекторът казва кой елемент да се оформи, а в къдравите скоби са свойствата. Всяко свойство завършва с ;

Цветови модели

  • red1) Име на цвят – английската дума: red, blue, green, yellow, black, white… Най-лесно, но има ограничен избор.
  • rgb(255,0,0)2) RGB = Red (червено), Green (зелено), Blue (синьо). Цветът се получава от смесване на трите, всяко от 0 (няма) до 255 (най-много).
    rgb(255,0,0) червено   rgb(0,255,0) зелено   rgb(0,0,255) синьо
    rgb(255,255,0) жълто   rgb(0,0,0) черно   rgb(255,255,255) бяло
  • #FF00003) HEX – шестнадесетичен (16-ичен) код. Това е същият RGB цвят, но числата са записани в бройна система с основа 16. В нея има 16 знака: цифрите 0–9 и буквите A–F (A=10, B=11, C=12, D=13, E=14, F=15). Кодът започва с # и има три двойки: #RRGGBB (червено, зелено, синьо). 00 е най-малко (0), FF е най-много (255).
    #FF0000 червено   #00FF00 зелено   #0000FF синьо   #FFFFFF бяло
  • hsl(0,100%,50%)4) HSL – цветът се описва с три неща:
    Hue – тон (нюанс): кой е самият цвят, ъгъл на цветното колело от 0° до 360°. 0° червено, 60° жълто, 120° зелено, 180° циан, 240° синьо, 300° виолетово.
    Saturation – наситеност (0%–100%): колко е „чист“ цветът. 0% е сиво, 100% е ярък цвят.
    Lightness – светлина (0%–100%): 0% е черно, 50% е нормален цвят, 100% е бяло.
  • rgba(255,0,0,0.5)5) RGBA / HSLA – като RGB и HSL, но с добавена прозрачност (alpha) от 0 (напълно прозрачно) до 1 (напълно плътно).
HSL нагледно
Hue (нюанс) 0° → 360°
Saturation (наситеност) 0% сиво → 100% ярко
Lightness (светлина) 0% черно → 50% цвят → 100% бяло
RGB смесва светлини: червено + зелено + синьо = бяло; червено + зелено = жълто

Съвет: с HSL лесно правиш светли и тъмни версии на един цвят – сменяш само Lightness: hsl(210,80%,30%) тъмно синьо, hsl(210,80%,85%) светло синьо.

Опитай: смени цветовете с HEX и HSL стойности по твой избор.

💻 Задача за Notepad++

Оформи страница за твоето хоби в тъмна тема.

  1. Напиши HTML със заглавие h1, два абзаца и един div с клас belezhka.
  2. В <style> задай тъмен фон (напр. #222) и светъл текст на body.
  3. Центрирай h1 и му задай цвят с HSL.
  4. За .belezhka задай пунктирана рамка (border: 2px dashed …), padding и закръглени ъгли.
  5. Със style="…" директно в един абзац го оцвети в друг цвят.

⭐ Бонус: Премести стиловете във външен файл style.css и го свържи с <link>.

Как да работя в Notepad++?
  1. Отвори Notepad++ → File → New (Ctrl+N).
  2. Напиши кода на задачата.
  3. File → Save as… (Ctrl+Alt+S) → в „Save as type“ избери Hypertext Markup Language file → напиши името от задачата (с .html) → Save. Запазвай всичко в една папка за уроците.
  4. Отвори файла с двоен клик – ще се отвори в браузъра.
  5. След всяка промяна: Ctrl+S в Notepad++ и F5 в браузъра. Ако кирилицата е счупена – Encoding → UTF-8.
