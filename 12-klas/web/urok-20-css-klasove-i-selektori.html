Урок 20: CSS: div, span, класове и селектори

<div> е универсален блок-контейнер: започва на нов ред и заема цялата ширина. Вътре може да има текст, картинки и други елементи.
<span> е вграден контейнер – стои в реда на текста и служи за оформяне на малка част от него.

Клас или id? Класът може да се ползва много пъти и един елемент може да има няколко класа (class="karta cherven"). Id е само един на страница. Имената се пишат на латиница, без интервали.
Класът е като „униформа“ за много хора, а id – като име на един човек

id или class – кога кое и защо

И двата атрибута „закачат име“ на таг, за да могат CSS и JavaScript да го намерят. Разликата е в едно просто правило: id е уникален, а class се повтаря.

id – като факултетен номер
В университета всеки студент има свой номер и два еднакви няма. По него се намира точно един човек. Така и id сочи точно един елемент в страницата.
class – като роля или група
Всички в групата „Модератори“ имат еднакви права. В групата има много хора, а един човек може да е в няколко групи. Така class описва вид елементи, които изглеждат или се държат еднакво.

Кога ползваме id – и защо

  • Елемент, който е само един в страницата – логото, главното меню, футърът. Името му е като адрес – не може да се обърка с друг.
  • Връзка към място в същата страница. Връзката <a href="#kontakti"> води до елемента с id="kontakti". Адресът трябва да е уникален, иначе браузърът не знае къде да отиде.
  • JavaScript. Скриптът трябва да намери точно един елемент: document.getElementById("kontakti").
  • Поле и неговият надпис: <label for="email"> се свързва с <input id="email">.
<header id="logo">TechShop</header>
<a href="#kontakti">Към контактите</a>
…
<footer id="kontakti">© 2026 TechShop</footer>

/* CSS: диез пред името */
#logo { font-size: 28px; }

Кога ползваме class – и защо

  • Много елементи, които изглеждат еднакво – карти на продукти, цени, бутони, новини в списък.
  • Промяна на едно място. Стилът е записан веднъж и важи за всички – ако промениш рамката, тя се сменя навсякъде едновременно.
  • Няколко класа на един елемент, разделени с интервал: общото е в единия клас, различното – в другия.
<div class="produkt">Слушалки Pro <span class="cena">89 лв.</span></div>
<div class="produkt promo">Слушалки Lite <span class="cena">49 лв.</span></div>
<div class="produkt">Слушалки Max <span class="cena">129 лв.</span></div>

/* CSS: точка пред името */
.produkt { border: 1px solid #cbd5e1; padding: 12px; border-radius: 10px; }
.promo   { background: #fef3c7; }
.cena    { font-weight: bold; color: #15803d; }

Така изглежда резултатът – един стил за трите карти, а втората има още един клас за различния фон:

Слушалки Pro 89 лв.
Слушалки Lite 49 лв.
Слушалки Max 129 лв.

Как да избера: попитай се „Ще има ли второ такова?“. Ако да – class. Ако е само един и ми трябва уникален адрес за връзка или за скрипт – id. При колебание за оформление избирай class: в реалните проекти оформлението почти винаги е с класове, а id се пази за връзки вътре в страницата и за JavaScript.
Приоритет: ако един елемент е оформен и с #id, и с .class и стиловете си противоречат, печели id, защото е по-конкретен.
Чести грешки: един и същ id на два елемента (JavaScript намира само първия); объркани знаци – # е за id, . е за class, а в HTML не се пише точка: class="btn"; интервал в id; различни главни и малки букви (Menu и menu са различни имена).

Кутийният модел

Всеки елемент е кутия: content (съдържание) → padding (вътрешен отстъп) → border (рамка) → margin (външен отстъп).

Всеки елемент в страницата е кутия с четири слоя

Как да работя в Notepad++?
  1. Отвори Notepad++ → File → New (Ctrl+N).
  2. Напиши кода на задачата.
  3. File → Save as… (Ctrl+Alt+S) → в „Save as type“ избери Hypertext Markup Language file → напиши името от задачата (с .html) → Save. Запазвай всичко в една папка за уроците.
  4. Отвори файла с двоен клик – ще се отвори в браузъра.
  5. След всяка промяна: Ctrl+S в Notepad++ и F5 в браузъра. Ако кирилицата е счупена – Encoding → UTF-8.
