Урок 25: JavaScript: DOM и събития – малка апликация

DOM е „дървото“ от елементи на страницата. С JavaScript намираме елементи, създаваме нови и реагираме на действията на потребителя.

КомандаКакво прави
document.querySelector("#id")намира елемент по CSS селектор (#id, .клас, p)
document.querySelectorAll(".k")намира всички съвпадения
el.innerText = "…"сменя текста
el.classList.toggle("gotovo")включва или изключва CSS клас
document.createElement("li")създава нов елемент; parent.appendChild(li) го вмъква
el.onclick = function(){…}реакция при клик
Когато JavaScript добави нов елемент в дървото, той веднага се появява на страницата
Добра практика: външният вид е в CSS клас, а JavaScript само го включва и изключва с classList.

Опитай: добави бутон „Изчисти всички“, който изпразва списъка (innerHTML = "").

Как да работя в Notepad++?
  1. Отвори Notepad++ → File → New (Ctrl+N).
  2. Напиши кода на задачата.
  3. File → Save as… (Ctrl+Alt+S) → в „Save as type“ избери Hypertext Markup Language file → напиши името от задачата (с .html) → Save. Запазвай всичко в една папка за уроците.
  4. Отвори файла с двоен клик – ще се отвори в браузъра.
  5. След всяка промяна: Ctrl+S в Notepad++ и F5 в браузъра. Ако кирилицата е счупена – Encoding → UTF-8.
