Нови неща в този урок: променлива (кутийка, която помни стойност), условие If … Then … Else (програмата избира какво да прави) и промяна на текст в слайда от макрос.

Променливи – кутийки с име

Променливата е място в паметта с име, в което програмата пази стойност. Представи си кутийка с етикет: на етикета пише tochki, а вътре е числото 3.

Променливата се създава (декларира) с Dim:

Dim tochki As Integer
Dim ime As String
  1. Dim – „създай“; tochki – име; As Integer – вид: цяло число. Новата числова променлива започва от 0.
  2. As String – текст. Новата текстова променлива е празна: "".
ВидКакво пазиПример
Integerцяло число (до 32 767)tochki = 4
Stringтекстime = "Мария"
Booleanда/не: True или Falseotgovoril = True
Shapeфигура от слайдаSet t = …Shapes("Rezultat")
Знакът „=“ тук не е „равно“, а „сложи в“. tochki = tochki + 1 се чете: „вземи старата стойност на tochki, добави 1 и сложи резултата обратно в tochki“.

Условия: If … Then … Else

С условие програмата сама избира какво да направи. Чете се като в живота: „Ако имаш 5 точки, тогава пиши „Отлично“; иначе ако имаш поне 3, пиши „Много добре“; иначе – „Опитай пак“.“

If tochki = 5 Then
    MsgBox "Отлично! Всичко е вярно!", vbInformation
ElseIf tochki >= 3 Then
    MsgBox "Много добре!", vbInformation
Else
    MsgBox "Прегледай урока и опитай пак.", vbExclamation
End If
  1. If условие Then – ако условието е вярно, се изпълнява блокът под него и всичко останало до End If се прескача.
  2. ElseIf – проверява се, само ако горните условия не са верни. Може да има няколко.
  3. Else – „във всички останали случаи“. Не е задължителен.
  4. End If – край на условието. Задължителен, когато блокът е на няколко реда.
ЗнакЗначениеПример
=равно (в условие)tochki = 5
<>различноime <> ""
> <по-голямо / по-малкоtochki > 2
>= <=по-голямо или равно / по-малко или равноtochki >= 3

Кратко условие на един ред няма нужда от End If: If ime = "" Then ime = "Гост"

🧪 Пробвай: кой клон се изпълнява?

Зелено – проверено и вярно; сиво – проверено, но невярно; бледо – прескочено.

MsgBox с въпрос + If

В урок 5 видя, че MsgBox с vbYesNo връща vbYes или vbNo. С If вече може да го използваш:

Sub Kraj()
    If MsgBox("Сигурен ли си?", vbYesNo + vbQuestion) = vbYes Then
        ActivePresentation.SlideShowWindow.View.Exit
    End If
End Sub

Когато взимаш отговора от MsgBox, скобите са задължителни.

Целият код с обяснения

Това е кодът от симулацията. Щракни върху обяснение, за да видиш редовете.

Dim tochki As Integer
Dim ime As String

Sub Start()
    tochki = 0
    ime = InputBox("Как се казваш?", "Тест")
    If ime = "" Then ime = "Гост"
    ActivePresentation.SlideShowWindow.View.Next
End Sub

Sub Veren()
    tochki = tochki + 1
    MsgBox "Браво! Верен отговор.", vbInformation, "Резултат"
    ActivePresentation.SlideShowWindow.View.Next
End Sub

Sub Greshen()
    MsgBox "Грешен отговор.", vbExclamation, "Резултат"
    ActivePresentation.SlideShowWindow.View.Next
End Sub

Sub PokajiRezultat()
    Dim t As Shape
    Set t = ActivePresentation.SlideShowWindow.View.Slide.Shapes("Rezultat")
    t.TextFrame.TextRange.Text = ime & ": " & tochki & " от 5 точки"
    If tochki = 5 Then
        MsgBox "Отлично! Всичко е вярно!", vbInformation
    ElseIf tochki >= 3 Then
        MsgBox "Много добре!", vbInformation
    Else
        MsgBox "Прегледай урока и опитай пак.", vbExclamation
    End If
End Sub

Sub Otnachalo()
    ActivePresentation.SlideShowWindow.View.GotoSlide 1
End Sub

    Стъпка по стъпка: направи теста

    Три пътеводителя: слайдовете, кодът, бутоните. Нова презентация, записана като .pptm (виж урок 5).

    Бърз начин за въпросите. Направи слайд 2 докрай – с действията на четирите бутона. После Ctrl+D (дублиране на слайд) 4 пъти. Действията се копират с бутоните. Смени само текстовете и размести бутоните – действието остава закачено за бутона, така че верният отговор е на различно място.
    Защо павилион? В обикновено слайдшоу щракване по фона или → минава на следващия слайд – играчът може да прескочи въпрос без отговор. В режим „Разглеждане в павилион“ слайдовете се сменят само от бутоните (и макросите). Изход: Esc.

    Задача за часа

    Тест-игра по ИТ тема

    Направи в PowerPoint тест от 5 въпроса с макроси: пита за името на играча, брои точките, показва резултата в слайда и дава оценка. Тествай го със съученик.

    ⏱ 1–2 учебни часа👤 индивидуално или по двойки🎯 20 точки

    Изисквания – точно в този ред

    1. Файл Test-Tema-Ime-Familia.pptm, 7 слайда: старт, 5 въпроса, резултат.
    2. 5 въпроса по една от темите вдясно, всеки с 4 отговора. Верният е на различно място в различните въпроси.
    3. Променливи tochki (Integer) и ime (String), декларирани горе в модула.
    4. Макроси: Start, Veren, Greshen, PokajiRezultat, Otnachalo – с коментар над всеки.
    5. Start нулира точките, пита за името (с „Гост“, ако е празно) и отива на слайд 2.
    6. Текстово поле на слайд 7 с име Rezultat; PokajiRezultat пише в него името и точките.
    7. Оценка с If / ElseIf / Else – поне 3 различни съобщения според точките.
    8. Режим павилион – слайдовете се сменят само от бутоните.
    9. Проба – съученик минава теста два пъти: веднъж с всички верни, веднъж с грешки.

    Какво предаваш

    • Файла .pptm
    • Екранна снимка на слайд 7 с резултата на съученика
    • Екранна снимка на кода
    • 2–3 изречения: какво направи If в твоя тест и коя грешка поправи
